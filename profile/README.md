## 中文

**MCSOG** 是一个只做一件事的站点：把 Minecraft 开服讲清楚。

从选服务端核心、配置运行环境，到长期运维与故障排查，教程按顺序排好；资源按用途归类。目标是让第一次开服的人也能一步步走完，而不用在论坛里翻几十个帖子。

线上站点：<https://mcsog.ndpreforged.com>

### 本组织下的仓库

| 仓库 | 说明 | 状态 |

| [MCSOG-Docs](https://github.com/Minecraft-Server-Opening-Guide/MCSOG-Docs) | 公开文档仓库：教程与百科的 Markdown 源文，**欢迎提交 Pull Request** | 公开 |

> 站点代码仓库暂不对外开放。文档相关的一切贡献都走 `MCSOG-Docs`。

### 内容范围

- **开服教程**：Java 版、基岩版两条主线，另有运维与安全、常见问题
- **版本百科**：版本时间线、服务端核心对比、常用指令等
- **资源索引**：服务端核心、插件、模组、数据包、工具软件（按用途分类）

### 怎么贡献

1. 到 [MCSOG-Docs](https://github.com/Minecraft-Server-Opening-Guide/MCSOG-Docs) Fork 仓库
2. 修改 `docs/zh/**` 或 `docs/en/**` 下的 Markdown
3. 提交 Pull Request，说明**改了什么**与**为什么改**
4. 合并后自动生效：**30 分钟内**进主仓库，**2 小时内**上线

发现错误、命令失效或版本过期，也欢迎直接开 Issue 或在 PR 里指出。

### 内容原则

- **正确优先**：版本号、命令、下载地址以官方来源为准，并给出可核对的链接
- **中文为主、英文同步**：中英两套文档路径一一对应
- **不夸大**：不确定的内容会标注，过期内容会更新或下线，而不是留在那里
- **注明来源**：引用第三方内容会标注出处与许可证

## English

**MCSOG** does exactly one thing: it explains Minecraft server hosting clearly.

From picking a server core and setting up the runtime, through long-term operations and
troubleshooting, the tutorials are ordered; resources are grouped by purpose. The goal is that
someone hosting a server for the first time can follow the whole path without digging through
dozens of forum threads.

Live site: <https://mcsog.ndpreforged.com>

### Repositories in this organisation

| Repository | Description | Status |
| --- | --- | --- |
| [MCSOG-Docs](https://github.com/Minecraft-Server-Opening-Guide/MCSOG-Docs) | Public documentation: the Markdown sources for tutorials and the wiki. **Pull requests welcome** | Public |

> The site source repository is not public for now. All documentation contributions go through `MCSOG-Docs`.

### What it covers

- **Hosting tutorials**: Java Edition and Bedrock Edition tracks, plus operations, security and FAQ
- **Version wiki**: version timeline, server core comparison, common commands
- **Resource index**: server cores, plugins, mods, data packs and tools, grouped by purpose

### Contributing

1. Fork [MCSOG-Docs](https://github.com/Minecraft-Server-Opening-Guide/MCSOG-Docs)
2. Edit the Markdown under `docs/zh/**` or `docs/en/**`
3. Open a pull request explaining **what** changed and **why**
4. Once merged it takes effect automatically: into the main repository **within 30 minutes**,
   live on the site **within 2 hours**

Spotted a mistake, a dead command or an outdated version? Open an issue or point it out in a pull request.

### Content principles

- **Correctness first**: version numbers, commands and download URLs follow official sources and link to them
- **Chinese first, English in sync**: the two trees mirror each other one to one
- **No overstating**: anything uncertain is marked, and outdated content is updated or retired rather than left in place
- **Credit sources**: third-party material is credited with its origin and licence
